# TolstoyLLM_v5: Радикально Оптимизированная Архитектура

**TolstoyLLM_v5** — это квинтэссенция инженерной мысли в области NLP, адаптированная для работы на потребительском железе. Мы создали модель, которая сочетает в себе гибкость экспертных сетей (MoE) и экстремальное сжатие памяти (XQuant).

---

## 🏗️ Спецификация архитектуры

| Параметр | Значение | Описание |
| :--- | :--- | :--- |
| **Тип** | Decoder-only | Только авторегрессионная генерация текста. |
| **Нормализация** | RMSNorm | Применяется перед каждым слоем (Pre-Norm). |
| **Активация** | SwiGLU | Fused-реализация с коэффициентом расширения 8/3. |
| **Внимание** | GQA | 32 головы запросов на 8 голов ключей/значений. |
| **Позиции** | RoPE | Rotary Positional Embeddings с поддержкой YaRN. |
| **Слои** | Sparse MoE | 8 экспертов, из которых активны 2 на каждый токен. |

---

## 💎 Ключевые преимущества v5

### 1. Эффективность памяти (XQuant-CL)
Благодаря встроенной системе квантования KV-кэша, модель v5 потребляет **в 2 раза меньше VRAM** при генерации длинных текстов по сравнению с v4. Это позволяет запускать контекстные окна до 8192 токенов на видеокартах среднего сегмента.

### 2. Спекулятивное ускорение (MTP Heads)
В архитектуру внедрены дополнительные головы предсказания. При включении режима `speculative_decoding`, модель генерирует сразу несколько вариантов продолжения фразы и проверяет их параллельно. Это дает ускорение генерации на **150-200%**.

### 3. Оптимизированное обучение (GaLore)
Интеграция с методом GaLore позволяет обновлять только низкоранговые проекции весов. Для пользователя это означает возможность обучать модель на 1.2B параметров на видеокарте с 12 ГБ памяти.

## ❓ FAQ (Технический раздел)

**В: Можно ли использовать модель для программирования?**
О: Пресеты `logic` и `medium` специально обучены на смешанных корпусах текста и кода. Они показывают лучшие результаты в логических задачах.

**В: Как работает Weight Tying в этой модели?**
О: Мы используем общие веса для входного эмбеддинга и финального линейного слоя. Это сокращает количество параметров на ~20% без потери "интеллекта" модели.

**В: Поддерживает ли модель FlashAttention-2?**
О: Да, если ваша видеокарта поддерживает архитектуру Ampere (RTX 30xx) и новее, фреймворк автоматически активирует FlashAttention через `torch.nn.functional.scaled_dot_product_attention`.
